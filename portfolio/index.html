Featured build · Space Jelly

A one-button space runner about a jellyfish that refuses to sink.

Space Jelly is a 2D endless runner in the Flappy lineage. You keep a glowing jelly afloat through gaps between neon tubes. The rules fit in one sentence, so every bit of quality has to come from feel: how the jump arcs, how the jelly tilts, how fast the tubes arrive.

The architecture is deliberately small. A singleton GameManager owns the run state, a singleton Score owns the counter and the saved best, and every other script does exactly one thing: move a pipe, spawn a pipe, loop the ground, scroll the nebula.

Game feel · Tuning lab

The code says 1.5. The scene says 3. That gap is the design.

Every value below is a serialized field from the Unity project. The scripts ship one set of defaults; the Game scene overrides them in the Inspector. Doubling the flap and cutting gravity to 0.65 turns a bird's hop into a jelly's slow drift. Move the sliders and play the screen beside them to feel it yourself.

Art direction · Neon nebula

Synthwave space, one warm yellow hero.

The world is cold cyan and magenta so the jelly is the only warm thing on screen. Your eye never has to search for the player. Tubes glow the same cyan as the nebula, so danger and scenery share a language while the jelly stands apart.
